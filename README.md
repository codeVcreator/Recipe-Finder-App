# Recipe Finder App

A responsive React app that helps users discover recipes based on their available ingredients — with YouTube video integration for every result.

**Live demo → [recipe-finder-app-codevcreator.vercel.app](https://recipe-finder-app-codevcreator.vercel.app/)**

---

## What it does

- **Ingredient-based search** — enter what you have, get matching recipes instantly
- **YouTube integration** — every recipe links directly to a matching YouTube tutorial
- **REST API** — fetches live recipe data from an external recipes API
- **Responsive design** — works across mobile and desktop
- **Clean, interactive UI** — built for ease of use with smooth search and browse experience

## Run locally

```bash
git clone https://github.com/codeVcreator/Recipe-Finder-App.git
cd Recipe-Finder-App
npm install
npm start
```

App runs at `http://localhost:3000`

> Add your API keys to a `.env` file if required — check the source for variable names.
